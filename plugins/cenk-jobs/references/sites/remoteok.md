# RemoteOK: site notes

Read by the fit check (its brief names the rule), and by a session that applies to a posting found on RemoteOK.

- RemoteOK's Apply button needs a paid plan. A RemoteOK posting is applied to on the employer's own careers page or
  board; with none found, the job is skipped with the reason "applies only through RemoteOK (paid)". Example: Acme's
  posting on remoteok.com, the same role on Acme's Greenhouse board: apply there.
